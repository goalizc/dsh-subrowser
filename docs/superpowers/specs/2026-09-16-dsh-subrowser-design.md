# DSH 浮动子浏览器插件 — 设计文档

- 日期：2026-09-16
- 状态：已获用户批准

## 1. 目标

为 DSH（DeepSeek Harness）Web 界面主聊天页实现一个**浮动子浏览器**插件：可在界面内打开多个可拖拽、可缩放、可最小化/关闭的 iframe 浏览器窗口，通过右侧居中的图标栏管理窗口，Esc 一键全部最小化，状态持久化到 localStorage。

## 2. 需求摘要（已与用户确认）

- 内容：任意 URL，以 iframe 内嵌；URL 输入框可折叠隐藏
- 多窗口：可同时打开多个子浏览器窗口
- 图标栏：右侧居中显示，含「+」新建按钮 + 已打开窗口的图标列表（点击图标切换显示/最小化）
- Esc：一键全部最小化所有窗口
- 窗口操作：仅「最小化（隐藏，通过右侧图标重新显示）」与「关闭」，不支持最大化
- 交互：标题栏拖拽移动 + 四角/边缘缩放
- 持久化：localStorage 保存窗口大小/位置/URL/折叠状态，跨会话恢复
- 集成形式：标准 DSH bundle 插件（package.json + cordis.patch.yml + lib/index.js 宿主 + assets 前端）
- 运行范围：仅主聊天界面（有 composer 输入区）
- 新建窗口：打开空白窗，URL 输入框自动聚焦

## 3. 方案选型

采用**方案 A：纯前端注入，宿主仅提供静态资源**。

- 与既有 dsh-whale-widget 架构一致，可 `dsh plugin add link:.` 一键安装
- 无外部依赖、离线可用；前端改动硬刷新即生效
- 受浏览器 iframe 限制：部分站点（带 `X-Frame-Options`/CSP）无法内嵌，窗口内提供「外部打开」兜底
- 否决方案 B（宿主反向代理改写页面，复杂度高、维护成本高）
- 否决方案 C（引入第三方拖拽库，与 whale-widget 自研原生风格不一致）

## 4. 插件结构与组件

```
z:\dsh-subrowser/
├── package.json          # dsh 插件元数据（name: dsh-subrowser，dsh.bundle.patch 指向 cordis.patch.yml）
├── cordis.patch.yml      # 挂载声明：insert id: dsh-subrowser
├── lib/
│   └── index.js          # 宿主侧：仅提供静态路由 /dsh-subrowser/widget.js（按 mtime 热读取）
├── assets/
│   └── subrowser.js      # 前端本体：全部交互逻辑
└── README.md             # 安装/使用说明
```

前端本体划分为四个命名空间模块（单文件 `subrowser.js`）：

| 模块 | 职责 |
|---|---|
| `SB.dock` | 右侧居中图标栏：「+」新建按钮 + 已打开窗口图标列表（点击切换显示/最小化） |
| `SB.window` | 单个浏览器窗口：标题栏拖拽、四角/边缘缩放、URL 输入框（可折叠）、iframe、最小化/关闭按钮 |
| `SB.manager` | 窗口生命周期：创建、激活置顶、最小化全部、Esc 监听、localStorage 持久化 |
| `SB.util` | 公共工具：DOM 创建、拖动/缩放数学、视口约束 |

**页面自检**：脚本注入后检查 `#root` 下是否有 `textarea` 或 `[contenteditable="true"]`（主聊天界面特征），否则不初始化（避免干扰插件市场等 SPA 视图，同 whale-widget 策略）。

## 5. 交互细节

### 5.1 窗口本体

```
┌─────────────────────────────────────────┐
│ ● ● ●    [URL 输入框]       外部▾  —  ✕ │  ← 标题栏（可拖动）
├─────────────────────────────────────────┤
│                                         │
│              iframe 内容区               │  ← 四角/边缘可缩放
│                                         │
└─────────────────────────────────────────┘
```

- 标题栏：左端三个圆点标识 + URL 输入框 + 右侧按钮区（「外部打开」菜单、最小化、关闭）
- URL 输入框可折叠：点击标题栏空白处或指定按钮折叠，仅保留按钮区；折叠状态持久化
- 拖拽：按住标题栏空白区/圆点移动；缩放：右下角 + 四边
- 缩放限制：最小 240×180px；窗口始终约束在视口内（拖动/缩放自动收敛）
- iframe 导航：输入 URL 回车即导航，自动补 `https://`
- 加载失败/站点拒绝内嵌：窗口内提示「该站点不允许内嵌，可点『外部打开』」；「外部打开」在新标签页打开
- 新建窗口：空白，URL 输入框自动聚焦

### 5.2 右侧图标栏（SB.dock）

- 垂直居中于视口右侧边缘：「+」图标 + 每个已打开窗口一个小图标
- 点击窗口图标：显示↔最小化切换；图标点亮表示窗口可见
- 全部窗口关闭后「+」仍在，可随时新建
- 图标栏固定，不提供拖出/隐藏（YAGNI）

### 5.3 键盘与层级

- Esc：一键全部最小化所有窗口（图标栏保留）；iframe 聚焦时不拦截（跨域 iframe 独立文档，天然不冲突）
- z-index：新窗口激活置顶；点击窗口提至最前

## 6. 数据流与持久化

### 6.1 状态模型

localStorage key：`dsh-subrowser:v1`

```js
{
  windows: [
    {
      id: 'w_172...',        // 时间戳+随机数
      url: 'https://...',    // 当前 URL（空串 = 空白待输入）
      x: 320, y: 40,         // 窗口左上角（相对视口）
      w: 720, h: 480,        // 尺寸
      minimized: false,      // 是否最小化
      addrHidden: false      // URL 输入框是否折叠
    }
  ]
}
```

### 6.2 读写时机

- 写：拖动/缩放结束时（非每帧）、导航/关闭/最小化/新建时，写一次 localStorage；连续操作防抖 300ms
- 读：页面加载初始化时读一次，恢复窗口集合
- 刷新后恢复为显示状态（所见即所得）
- 窗口上限：最多 8 个；超限时新建提示「窗口数已达上限」

### 6.3 错误处理

- iframe 加载失败/拒绝内嵌 → 窗口内提示 + 外部打开兜底
- localStorage 不可用/数据损坏 → 静默降级为空状态（仅图标栏），不影响 DSH 本体
- URL 非法 → 输入框标红提示，不导航

## 7. 宿主路由与验证

### 7.1 宿主 lib/index.js

| 路由 | 行为 |
|---|---|
| `GET /dsh-subrowser/widget.js` | 读取 `assets/subrowser.js` 按 mtime 下发（热更新） |

- 通过 `cordis.patch.yml` 的 `insert` 挂载，DSH 宿主按 bundle 机制注入前端脚本到各 index 页面
- 纯前端静态资源，无凭据/无外部 API，不接入 DSH 信任栅栏

### 7.2 验证清单

1. `dsh plugin --profile web add link:z:\dsh-subrowser` 安装成功
2. `dsh --profile web --dump-config` 能看到 `dsh-subrowser` 在 bundles 里
3. `curl http://127.0.0.1:3080/dsh-subrowser/widget.js` 返回 200 JS
4. 浏览器 F5 后：右侧图标栏出现；「+」新建窗口可输入 URL 并加载；可拖拽缩放；Esc 全部最小化；刷新后状态恢复

### 7.3 测试方式

纯前端交互，验证以手动浏览器操作为主，不引入单元测试框架（遵循 whale-widget 模式）。
